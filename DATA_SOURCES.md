## Required preprocessing
1. Download, record source URL/time, file hash and product label; run `gdalinfo -json` or Rasterio inspection. Verify CRS, affine, units, pixel size, dimensions, mask/nodata, extent and plausible numeric samples.
2. Transform all footprints into common Mars coordinates and choose pilot intersection. Crop in projected metres; preserve CRS and nodata. Align analytical rasters; use nearest-neighbor for categorical layers. No Earth CRS shortcuts.
3. Derive slope using elevation gradient and true horizontal metres in local projected grid; check projection scale and use masks around missing neighbors. Keep native resolution or document resampling.
4. Generate lightweight outputs and manifest: product ID, instrument/mission, publisher, source URL, publication/acquisition dates if known, resolution, CRS, extent, units, nodata, license, checksum, processing steps and status (`catalog`, `downloaded`, `validated`, `derived`, `unavailable`). Show provenance in UI.

### S1 — CRISM / MRO (M5)
[USGS PyHAT D2300 reference](https://pubs.usgs.gov/publication/ofr20251038/full) describes D2300 as a 2.3 µm drop parameter used to examine hydrated minerals, including clays; it does not make the index a unique mineral identification.
[PDS source and current product families](https://pds-geosciences.wustl.edu/missions/mro/crism.htm), [exact MTRDR bundle](https://pds-geosciences.wustl.edu/mro/mro-m-crism-5-rdr-mptargeted-v1/mrocr_4001/), [bundle README](https://pds-geosciences.wustl.edu/mro/mro-m-crism-5-rdr-mptargeted-v1/mrocr_4001/readme.txt), [product SIS](https://pds-geosciences.wustl.edu/mro/mro-m-crism-2-edr-v1/mrocr_0002/document/crism_dpsis.htm), [ODE REST manual](https://oderest.rsl.wustl.edu/ODE_REST_V2.1.6.pdf). Validated scene `FRT000047A3` / MTRDR `frt000047a3_07_if166j_mtr3` (orbit 2743; observation 2007-02-26 04:34:15.930–04:36:23.656 UTC) has 808 × 847 samples and 489 float32 I/F bands, with native projected scale about 18 m. Its native footprint is approximately 77.375951–77.642025°E, 18.442814–18.687974°N. The associated `frt000047a3_07_sr166j_mtr3` summary image has 60 float32 bands; band 40 (1-based) is D2300, a dimensionless 2.3 µm spectral-drop parameter. The SR raster is noise-remediated and summary processing spatially interpolates flagged outliers. D2300 is sensitive to some hydrated-mineral spectral behavior (including clays), not a unique mineral identification, concentration or deposit. **Actual pilot result:** source footprint polygon intersects 11,358,784.735 m² (45.435%) of the 25,000,000 m² map area; nearest-neighbour reprojection gives 28,095 valid 20 m grid cells (44.952%). The runtime continuous overlay exposes the measured index and nodata only, without classification threshold. Exact acquisition, hashes, label/ODE footprint, projection and pixel statistics: `evidence/m5/crism-validation.json` and `data/processed/crism/manifest.json` (generated, ignored runtime data). NASA's [Jezero mineral illustration](https://www.jpl.nasa.gov/images/pia23380-jezero-crater-minerals/) supports published regional context, not a georeferenced resource raster.
